# 01_全体概要

## システムの大枠
この一式は、複数ブランドサイトの SEO 運用を GAS と複数スプレッドシートで回す仕組みです。

主な機能は次の通りです。

- GSCデータ取得・蓄積
- ブランド横断ダッシュボード生成
- SEO改善候補抽出
- GPT用プロンプト生成とAPI実行
- HTMLスナップショット取得
- 差分ログ生成
- 更新前後のGSC影響分析
- 内部リンク監査
- 禁則ワード検査
- GSCクエリベースのキーワード候補抽出
