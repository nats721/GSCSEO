# 06_初期レビュー観点

## 1. source 構成は固定
今回の前提では、`source/` のフォルダ名・ファイル名は固定です。
最初のレビューでは、構成変更よりも**ロジックとシート契約**に集中した方が安全です。

## 2. シート契約レビュー
次を重点確認してください。
- `各ブランドサイト管理＿メイン` の共通ヘッダ
- `GSC履歴` の `GSC最新 / GSC履歴 / GSC日別`
- `SEOプロンプト作成` の `GPTプロンプト`
- `HTMLキャッシュ` の 11列固定契約
- `禁則ワードチェック` のヘッダ有無差異
- `内部リンクマスタ` の `内部リンク_一覧 / 階層マスタ`

## 3. Excelエクスポート上の注意
添付された xlsx では `IMPORTRANGE` や Google 独自関数が `__xludf.DUMMYFUNCTION(...)` として見えます。
これは **Excel 側での式表現**であり、元の Google Sheets 側の実式とは別です。

## 4. 実行環境依存
- Search Console API
- Script Properties (`OPENAI_API_KEY`)
- Trigger
- Drive保存
は静的レビューだけでは完全検証できません。

## 5. 未添付ブック
- `HTMLキャッシュ`
- `SEO短期結果確認`
は実ブック未添付のため、断定的な改修は避けるのが安全です。
