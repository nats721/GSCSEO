# 05_データフロー

## 主な流れ
1. `各ブランドサイト管理＿メイン` の `設定` と各ドメインシートを起点に URL 一覧を持つ
2. `コード.js` が Search Console API からページ単位GSCを取得し、`GSC履歴` に書き込む
3. `ブランド一覧サマリ作成(日時).js` が `概観` / `概観_履歴` を更新する
4. `HTMLキャッシュ.js` が各URLの本文HTML・title・meta等を `HTMLキャッシュ` に保存する
5. `差分取得.js` が `Snapshot` を取得し、`差分比較.js` が `ChangeLog` を生成する
6. `更新間のGSC差分調査.js` が `GSC履歴` と `HTMLキャッシュ` を照合し `UpdateImpactReport` を作る
7. `SEOプロンプト作成.js` が
   - GSC
   - HTMLキャッシュ
   - 禁則ワード
   - URL管理
   を見て `SEOプロンプト作成` の改善候補と `GPTプロンプト` を作る
8. `プロンプトAPI実行.js` が OpenAI Responses API を叩き、出力本文を保存する
9. `内部リンクマスタ.js` / `親子関係正規化.js` / `階層マスタ更新.js` が内部リンク監査系シートを更新する
10. `禁則ワード.js` が本文を走査し、`禁則ワードチェック` の `チェック結果` を更新する
11. `GSCキーワードベース.js` がキーワード候補・カニバリ候補を `GSCキーワード調査` に出力する

## 静的レビューで要確認の接点
- URL列の完全一致
- 分類列（TP / SP / MC / SC / ST / NW / -）
- `GSC最新` と `GSC履歴` の列契約
- `HTMLキャッシュ` の固定11列
- `GPTプロンプト` の G〜L 列追加契約
