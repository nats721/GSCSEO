# 07_Codex依頼テンプレート

以下をそのまま初回依頼に使えます。

---
このリポジトリは GAS ベースの SEO 運用一式です。

最重要ルール:
- `source/` 配下のフォルダ名・ファイル名は変更しない
- まず docs を読んでからレビューする
- 未添付シート（HTMLキャッシュ / SEO短期結果確認）は断定しない

やってほしいこと:
1. `docs/02_シート仕様.md` と `docs/04_スプレッドシート対応表.md` を読み、シート契約を把握
2. `source/` を横断して、各ファイルの役割を要約
3. バグの可能性・保守性の弱い箇所・列契約の危険箇所を洗い出す
4. 指摘を次の3段階で分類
   - すぐ直せる安全な修正
   - 実データ確認後に直す修正
   - 仕様確認が必要な修正
5. 変更案は diff ではなく、まずレビュー一覧で出す

特に見てほしい観点:
- GSC系の入出力列
- GPTプロンプト列 G〜L の運用
- 差分取得 → ChangeLog 生成
- HTMLキャッシュ 11列固定契約
- 内部リンク監査系のシート依存
---

必要なら次段階で、
「安全な修正だけを別ブランチで実装」
まで進めてください。
