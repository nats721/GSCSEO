# Codex引き継ぎパッケージ v2

このパッケージは、GASコード一式を Codex / Git でレビュー・改修するための引き継ぎ用です。

## 今回の更新点
- `source/` 配下は、**アップロードされた `ソース.zip` のフォルダ構成をそのまま保持**しています。
- 列名・シート仕様は、アップロードされた Excel から再取得して更新しました。
- 重複アップロードがあるブックは、本文ドキュメント上では次を最新版として扱っています。
  - `各ブランドサイト管理＿メイン (4).xlsx`
  - `GSC履歴 (2).xlsx`

## 主要フォルダ
- `source/`  
  GASソース。**フォルダ名・ファイル名は変更しない前提**です。
- `docs/`  
  システム概要、シート仕様、データフロー、Codex依頼テンプレート。
- `metadata/`  
  ソース棚卸し、シート見出し一覧。
- `references/spreadsheets/`  
  添付された Excel 一式。
- `references/original/`  
  元の `ソース.zip`。

## 注意
- `HTMLキャッシュ` と `SEO短期結果確認` は今回の Excel 添付がないため、完全な列仕様は未確定です。
- `禁則ワードチェック.xlsx` の `禁則ワード` シートは **ヘッダなし** です。
- `source/` 内の日本語ファイル名は、zip上では `#UXXXX` 形式で保存されています。これは**元のまま**です。
